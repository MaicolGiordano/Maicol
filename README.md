## Featured projects

### [Corporate Credit Risk Lab](https://github.com/MaicolGiordano/Corporate-credit-risk-lab)

Machine learning project for predicting corporate bankruptcy using financial 
statement data. It compares Logistic Regression and XGBoost, with particular 
attention to class imbalance, threshold selection and risk scoring.

**Tools:** Python, pandas, scikit-learn, XGBoost, matplotlib

---

### [ECB Interest Rate Pass-Through](https://github.com/MaicolGiordano/ECB-interest)

Econometric analysis of the transmission of ECB policy rates to mortgage rates. 
The project uses distributed lag models, stationarity tests and HAC standard errors.

**Tools:** Python, pandas, statsmodels, matplotlib

---

### [Value at Risk Interactive Dashboard](https://github.com/MaicolGiordano/VaR-interactive-Dashboard)

Interactive application for portfolio risk analysis using Historical, Parametric 
and Monte Carlo Value at Risk, Expected Shortfall and portfolio visualisations.

**Tools:** Python, Streamlit, financial modelling, data visualisation

---

### [Housing Affordability in Italy](https://github.com/MaicolGiordano/housing-affordability)

Econometric project examining the relationship between housing affordability, 
mortgage rates, inflation and labour-market conditions in Italy.

**Tools:** R, tidyverse, ggplot2, Quarto, econometrics
